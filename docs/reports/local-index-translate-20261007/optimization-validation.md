## 已实现的流程

1. 原片及配置、代码、阶段依赖绑定运行记录，拒绝把旧检查点重新盖章为新运行。
2. 识别后用另一套本地 ASR 核对原声，保留分歧和音频证据，不静默改写原文。
3. 场景/人物分析先隐藏声纹标签。逐句重新推断说话角色、受话者、转述对象、动作主体和代词所指，再与原始声纹分组对照。
4. 同一个声纹簇允许对应多个角色，同一个角色允许跨声纹簇。原始声音标签、源文字和时间戳保留；语义角色单独送入翻译。
5. 逐句判断必须引用实际对白。缺乏证据、原文不存在的代词引用、转述对象缺失等判断退回 unknown；源文字变化会使旧角色映射失效。
6. Index 执行一次自然翻译。针对实测中“自审把自然英文改成逐字直译”的问题，当前默认 `translation.review_mode: audit_only`：只记问题，不覆盖译文。其他修复模式仍受内部标签、币种等检查约束，最终审计只读。
7. 语义译文与显示字幕分开；显示切分不重新改写台词，配音语义单元保留。阅读速度、短字幕及估计对齐明确报告。

| 人工角色、语义、字幕观感 | pending | 尚未完成独立逐句听辨验收 |

影片的关键反例是“……三天之后给你一百八十万……他的腿”。模型曾声称这一句的主语是“我”，并把转述人当成付款人，但这一行原文没有“我”。新检查将其退回待复核，避免错误角色关系被当成确定事实。另一轮中，模型仅被告知“声纹可能有错”时仍大多沿用声纹分组，因此最终改为先隐藏标签再分析。

原文还存在“出生剿匪”“截杀我的腿”“菲菲”等识别疑点。它们不能单靠重新命名人物解决。预览里出现的相关错误译法是待复核问题，并不代表已完成源文纠错。

## 原片运行与复用记录

本轮先从原片运行 stable-ts，因末尾语音覆盖检查失败而停止；随后试跑 Qwen3-ASR 加独立强制对齐，产生新的原文/声纹/时间记录。该路线的时间戳来源明确标为 80 ms 声学强制对齐，不冒称 ASR 原生时间戳。它仍是可选实验路线，项目默认 ASR 未自动切换。

后续角色和审校迭代复用本轮已核验的原片 ASR，以及相同模型/提示词的请求缓存；不是多次独立的全新 ASR 实验。具体链路见 [复用记录](/Users/vanch/VideoLingo-plus/run_workspaces/index_quality_review_20261007/upstream_reuse.json)。标准流水线停在翻译审校，额外复核预览由候选稿单独导出，`accepted: false`，没有绕过正式交付门槛。

## 下一步需要解决的能力缺口

逐句角色重判的结构已经支持，但当前 Index 实测不足以可靠承担人物关系推理和最终裁判。建议 Index 专门翻译，角色理解与审校另接经过验证的本地通用推理模型；源文听辨分歧仍要单独解决。也可维持现有模型并人工确认角色/原文疑点。

V9、V13 与本轮的输入分段和识别结果不同，尚不能据此宣布某个翻译模型更好。模型优劣比较仍需同一份核实原文、同一角色资料和独立盲评。
