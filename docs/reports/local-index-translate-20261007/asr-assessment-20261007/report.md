# ASR 修复与原片实测

这段《让子弹飞》的问题需要在源文阶段处理。已修复文字删除和对白拆散，并加入本地 MOSS 识别、独立词时间对齐及有证据的源文校订入口。默认识别不调用翻译模型纠错。

## 原因与改动

1. 原流程外部按约 25 秒切块，识别容易从一句话中间重新开始。Whisper 现在默认保留完整上下文；本地 MOSS 使用最多 180 秒的识别块。
2. 时间清洗曾删除短词、零时间词和重复词；导出还删除超过 20 字符的词记录。现在保留文字，零时间记录合并到同一句最近的有时间记录，重复只作疑点记录。
3. 原流程只导出词，没有保留识别器的完整对白和标点；声纹误分组会拆词，相同声纹还会合并相邻人物。现在保留识别分句和标点，声纹标签不重写文本。
4. 源文按逗号及字幕长度再次拆分，会拆散承诺中的付款者、收款人和义务。本地路线保留完整识别单元用于角色理解、翻译，译后另作显示分行。
5. 校订必须匹配原音频哈希、修改前文字和证据；原始识别回执保留。校订发生在翻译之前，随后重新对齐词时间。电影对白只保存在本例工作区，通用代码没有电影台词替换规则。
6. 可配置外部源文检查；检查失败即停止进入翻译。识别、声纹、词时间、翻译的证据分别保存。

本地默认路线是 MOSS 8bit 识别原始无损音频，再由 Qwen ForcedAligner 测量词时间。对齐时间是独立推算结果，不是 MOSS 原生逐词时间。Whisper 路线继续可选；本地对齐不支持的源语言明确报错。

独立 Qwen 见证保留识别分歧；两模型一致不等于正确，分歧也不能证明哪一方错误。片尾残缺对白不补写。源文覆盖通过仅说明已检测语音有文字覆盖，不说明文字全部正确。
