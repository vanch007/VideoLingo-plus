# 配音音色与情绪独立保真的流程优化

日期：2026-09-26。范围：VideoLingo 的本地 IndexTTS2.5 主路线；只使用输入视频、分离人声、ASR 与匿名说话人信息，不要求电影台词、角色名单或外部人物设定。

## 结论

根据用户试听反馈，当前默认改为混合策略：短句/碎句使用“同角色稳定音色参考 + 当前原句情绪参考”；语音信息充足的长句直接使用当前原句同时提供音色与情绪。固定音色参考不再应用到所有长句。以下初版对照数据保留为历史证据，不代表混合策略生成结果。

当前可调整的分类规则：原句不足 2 秒，或原始台词去除连续重复后不足 4 个汉字/词，或上游设置 `reference_is_fragment=true`，走固定音色 + 原句情绪；其余默认原句双用。使用原始台词与原始时间，不能按译文变长或变短改变分类。2 秒/4 单元是初始工程参数，尚非跨数据集校准阈值；未声称能自动识别所有语义碎句。未知角色不借用其他人的锚点，显式参考覆盖继续优先。

长句两个参考指向同一个原始人声切片，不混入其他台词的固定音色锚点。超过 8 秒只保留诊断提示，不因为长度强制切碎或改为固定音色。缺失、静音、时间重叠仍明确报错。

本轮已修复上游参考断流、权重传递、缓存失效、短句静音和补救后端静默丢失情绪的问题，并完成真实音频小样验证。长对白情绪分段、基于校准指标的自动候选选择与完整成片感知验收仍属后续工作，不能把基础接线完成写成全流程听感通过。

## 1. 根因与证据边界

| 流程位置 | 本次发现 | 后果 |
|---|---|---|
| 任务表 → TTSRequest | 现有 30 行任务无 `emotion_ref` / `emotion_ref_audio`；构造器只转发已有字段 | 切换 `speaker_anchor` 后，每句没有独立情绪输入 |
| 适配器 → IndexTTS | 已支持情绪音频参数，但没有显式传递 `emo_alpha` | 只修字段仍会继承本地 CLI 的 0.6 默认值 |
| 本地 2.5 运行时 | `generate_v25.py::_emotion_vector` 混合两种参考的情绪向量 | 音色锚点里的情绪仍可能污染目标情绪 |
| 参考评分 | 对 F0 高于 200 Hz 的候选施加惩罚，且用 YIN 的非零输出冒充浊音比例 | 高音角色与正常激动表达被误伤，不能据此证明“女声已消除” |
| 缓存与续跑 | 原指纹未绑定自动选择的音频内容、情绪来源、权重；阶段完成主要看文件存在 | 配置已改，旧音频仍可能被复用 |
| 单句补救 | `I...` 等单字符文本被直接变为静音 | 重要的犹豫、应答、感叹在补救时消失 |
| 补救后端 | 内容不佳时可以切换到只克隆音色的后端 | 内容分数改善掩盖情绪能力降级 |
| 验收 | 现有质量门禁主要检查内容、时长、文件完整性 | “30 ok”不能推出角色音色与情绪合格 |

音色偏离的全部原因仍不能归结为某个单一参数。说话人标签错误、参考混入他人、跨语言模型漂移、短句统计不稳定也需要检查。本轮直接证实的是上述数据流断点与评分、缓存缺陷。

官方用法：<https://github.com/index-tts/index-tts/blob/main/README.md>，音色输入 `spk_audio_prompt` 与情绪输入 `emo_audio_prompt` 独立。本机 MLX 对应 `--ref-audio`、`--emotion-ref-audio`、`--emo-alpha`，并支持 CSV 逐行覆盖。

## 2. 正确的数据流

```text
原视频
  ├─ 分离背景音乐/环境/动作音效 → 全时长背景轨 → 最终混音
  └─ 分离人声 + 原始时间轴
       ├─ ASR 原生字词时间 + Nemotron 匿名说话人 → 说话人/对白单元
       ├─ 同角色清洁语音池 → speaker_ref：稳定身份
       └─ 当前对白原句 → emotion_ref：本句表演

全文理解 + 角色关系/语言习惯 + 白话动作意图
       ↓ 约束翻译与时长改写，不覆盖音频情绪证据
翻译文本 + speaker_ref + emotion_ref + emo_alpha
       ↓
IndexTTS → 内容、身份、情绪分别检查 → 有限重试
       ↓
原时间轴对齐 → 保留内部停顿 → 背景混音 → 成片检查
```

“角色性格”是跨对白相对稳定的表达倾向；“情绪”是当句状态。一个角色可以平静、讽刺、愤怒、犹豫；不能把角色画像固定成一种情绪标签。声学原句优先，翻译后的文字情绪识别仅作补充。

## 3. 分阶段执行方案

### A. 双参考基础接线：本轮已实现

1. 短句/碎句按匿名 speaker 选择稳定锚点，长句使用自身原句音色。移除绝对音高惩罚，锚点按时长、有效能量占比和削波比例作初筛。此评分只是参考质量启发式，不是声纹验收。
2. 情绪从 `vocal.wav` 的当前行原始起止时间截取；没有 WAV 才使用分离人声 MP3。与音色参考的前后扩展分开，不为达到音色最短时长借用旁人的情绪。
3. 允许短情绪片段，标记不足 0.75 秒的样本为需检查；超过 8 秒标记可能含情绪变化。这两个值是诊断触发值，不是自动情绪合格阈值。
4. 原句为空、静音、缺失或与其他任务时间重叠时明确失败；未知说话人只允许使用自己的参考，不能直接借用另一个角色。
5. `emo_alpha` 在单句、批量与补救路径一致传递；当前从 1.0 开始保留本句情绪，同时支持行级覆盖。配置、参考 hash、原句窗口变化使旧生成失效。
6. 写入 `reference_manifest.json`（计划）和 WAV 对应 `.conditioning.json`（实际生成回执），区分计划输入与真实生成证据。
7. 需要独立情绪时拒绝静默切换到只支持音色参考的后端；改写文本不能改变原句所属角色或丢掉情绪来源。
8. 续跑重新检查参考计划，重生成后重新安排混音、封装；单句缓存也检查对应回执。
9. 不再把非空单字符台词直接替换成静音。

### B. 原句情绪单元：下一优先级

当前部分任务长达 8–10 秒，内部可能从质问转为重复、喊叫或停顿。整行只有一个情绪向量会平均掉变化，这是双参考接线后仍会出现的上限。

执行：

1. 在原生字词时间轴上建立 `utterance_id`，说话人切换与未知区间是硬边界。
2. 利用语句边界、原音停顿和能量/相对音高的变化定位表演单元；不能仅按固定秒数切碎句子。
3. 每个单元保存原始字词范围、speaker、语音置信度、重叠比例、声学边界、语言行为与情绪证据。语义判断与声学证据冲突时保留不确定性。
4. 翻译保留 `utterance_id` 映射。不同说话人或不同表演单元不因节约 TTS 调用被合并。
5. 短句优先保留自己的情绪参考；只有同一说话人、同场景、无情绪转折的相邻语音才允许扩展，并记录扩展原因。
6. 笑声、喘气、叹气等与语言无关的事件可以保留原始分离人声事件；不可为了填满时长编造英文台词。需与翻译语音窗口去重，防止双重发声。

验收：所有生成单元有可追溯原始范围；跨角色扩展为零；短句不静音吞掉；分段后无新增遗漏、重复和越界。现有 ASR/说话人分段错位必须作为上游问题返回，不能让 TTS 用错误窗口自行猜测。

### C. 音色池与情绪参考的独立清理

1. 每位 speaker 建立多候选池，优先 3–8 秒连续、无重叠、无强音乐泄漏、不过载的声音；不是强迫每个角色都有某种低音。
2. 用同角色候选声纹之间的相似度选择代表样本，排除离群样本；角色标签只提供候选集合，不能自行证明参考纯净。
3. 音色参考可做必要的清洁；情绪参考避免强去噪、整体响度压平或删除内部停顿。语气所需的音高变化、力度、呼吸不能当成噪声一起删掉。
4. 换音色候选时保持当前原句情绪不变；换情绪参考时保持音色候选不变，保留可比较的实验条件。

验收：候选选择理由、声音 hash、角色内相似度、跨角色对比都可追溯。没有足够同角色证据时写 `unknown`，不默认成 S01，不根据性别预设选择低音。

### D. 有限候选生成与多条件选择

本地运行时的关系可写为：

`情绪条件 = (1 - alpha) × 音色参考情绪 + alpha × 原句情绪`

alpha=0 会回到音色参考的表演，alpha=1 最大限度使用原句情绪。这个插值不是物理意义上的“只调情绪强度”，不同声学条件仍可能影响生成身份与发音。

建议策略：

1. 先按混合策略选择参考：短句用固定角色锚点 + 原句情绪 + alpha=1.0；长句使用原句音色与情绪，不一律套固定锚点。
2. 仅在有退化证据的单元生成有限候选：先换同角色备用锚点、保持原句情绪；再比较 0.85 等较小幅度权重变化。
3. 将内容完整、身份一致、情绪保真、时长可接受作为分别必须满足的条件，不能用一个加权总分掩盖任一失败。
4. 若降低权重改善声纹却把愤怒/讽刺/犹豫抹平，该候选淘汰；若情绪增强导致另一角色成为最高声纹匹配，候选同样淘汰。
5. 重试预算有限，候选都不合格时输出真实失败原因与候选产物，不静默切换成平静声音或另一后端。

相似度门槛须用本项目的同人异情绪、异人同情绪、中英跨语言样本校准。不能照搬一个 0.7 阈值，也不能用“F0 都小于 195 Hz”作为身份证明。短句统计尤其不可靠，应单独分层评估。

### E. 时间轴与翻译联动

1. 先按正确情绪生成自然语音，测量真实发声与停顿，再判断是否需要时间适配。
2. 超时先做保留言语行为的翻译压缩：质问、重复、犹豫、讽刺、强调与施受事关系不可因压缩丢掉。
3. 不为填满窗口机械加词；短反应允许保留原片里的空白、呼吸与停顿。
4. 继续使用现有自然变速上限与不截断实质语音的限制；不通过降调修补所谓女声、不大幅变速抹平表演。
5. 同时评估裸生成音频和时间适配后的音频，防止前者有情绪、后者被后处理破坏。
6. 最后复核背景轨连续性、动作音效保留、对白清晰度及角色切换时点。

## 4. 验收标准

| 维度 | 必需证据 | 通过标准 |
|---|---|---|
| 参考传递 | 行级计划、生成回执、输入 hash | 每行实际使用正确音色/情绪参考；单句、批量、补救一致 |
| 原始映射 | 字词/对白范围、speaker、重叠检查 | 不跨角色借用；无来源、混叠或低置信度明确暴露 |
| 内容 | ASR 回读及缺头缺尾检查 | 现有内容门禁通过；数字、否定、称谓、施受事不得只靠平均分掩盖 |
| 音色 | 声纹与本角色/其他角色的比较 | 本角色优先，不能牺牲身份换取情绪；阈值需分语言/长度校准 |
| 情绪 | 原句与配音的情绪/韵律比较 | 原句主要表演保留；不能通过全部变平静取得声纹高分 |
| 同步 | 发声起止、时间窗口、最终音轨 | 遵守既有边界与自然变速约束，无截词、漏句与新增跨角色重叠 |
| 背景 | 分离背景与最终混音的全时长检查 | 音乐、环境和动作音效持续存在，没有因重配音丢失 |
| 缓存 | 改情绪文件/权重/音色参考后重跑 | 受影响行重生成，下游混音更新，旧成片不假装新结果 |

本轮新增 `quality_gate.scope = content_timing_audio_integrity` 与独立 `perceptual_quality` 状态。无声纹/情绪验收证据时标为 `pending` / `missing evidence`；不能由内容门禁直接把整体状态写成 accepted。

自动声纹/情绪校准与候选选择尚未接入生产闭环，因此目前这一感知状态仍为 pending。日常流程的目标是基于原视频自动验收；人工对照只用于模型/策略基准校准，不要求每条视频查外部角色资料。

## 5. 本轮实测与交付边界

四个单元覆盖 S01、S02、S03 和一个 0.46 秒短句，保持文本、音色参考、种子一致，对比“仅音色参考”与“双参考”。生成时关闭时间拉伸，避免把后处理差异混进参考策略实验。

第一组 8 段结果：

| 行 | 角色 | 本角色 CampPlus：旧→双参考 | 原句情绪向量：旧→双参考 | 解释 |
|---|---|---|---|---|
| 12 | S01 | 0.720→0.690 | 0.770→0.756 | 不是每句加入情绪参考都必然提高代理分 |
| 21 | S02 | 0.791→0.660 | 0.439→0.713 | 情绪显著改善，同时有身份相似度损失，需候选比较 |
| 26 | S03 | 0.744→0.798 | 0.789→0.814 | 两项代理指标同时改善 |
| 15 | S03 | 0.453→0.361 | 0.599→0.826 | 极短句声纹不稳定；时长 0.71→0.43 秒，原句 0.46 秒 |

四行的声纹最高匹配均仍是自身 speaker。CampPlus 与 GPT 情绪向量都是模型相关代理指标；本实验未校准跨语言绝对阈值，也未证明主观听感全部合格。

补测 alpha=0.85（另 4 段，累计 12 段）后，第 21 行声纹相似度为 0.699、情绪相似度为 0.798，相比 alpha=1.0 两项均提高；第 15 行分别为 0.451、0.834，但回读由 alpha=1.0 的 `I` 变为 `Hi`。因此不能统一把 0.85 宣布为最佳权重，也不能单看两项相似度就通过短句内容。这支持“逐单元、多条件候选筛选”，而非一刀切压低或拉满权重。

对现有 30 行参考作只读任务审计，所有行均可建立独立情绪窗口。自动音色锚点为 S01→12、S02→27、S03→26；第 10 行身份未知，只使用自己的第 10 行参考。7 行超过 8 秒，3 行不足 0.75 秒，进一步的情绪单元分割/短句策略有明确触发对象。审计保存为首组小样目录中的 `all_reference_audit.json`。

第 26 行仍有 `taels` 被回读成 `tiles` / `dollars` 的差异，不能仅因分数超过 0.88 就宣布金额单位正确。字幕文本本身来自当前 ASR，不能由这次 TTS 实验证明源台词准确。

产物在 `run_workspaces/indextts_dual_conditioning_20260926/`。`*_comparison.wav` 的播放顺序为：原句 → 仅音色参考 → 双参考，中间间隔 0.65 秒。补充 0.85 权重结果单独保存在 `run_workspaces/indextts_dual_conditioning_alpha085_20260926/`。

本轮没有替换 `output/AI配音.mp4`，也没有把小样当作从 ASR 到最终混音的完整重跑证据。全量重跑应在候选策略验证后使用独立运行目录，保存配置、模型、参考、生成、混音及最终产物指纹。
