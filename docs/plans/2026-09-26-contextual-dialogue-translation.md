# 无外部参考的全文与角色感知翻译优化方案

日期：2026-09-26。状态：proposal，尚未实施、未进行效果回归。本轮只读核查源码、配置与当前产物，并新增本方案；不更改程序、配置、原文、译文或视频。

## 1. 推荐决策

采用“源对白证据 → 全片理解 → 场景与角色状态 → 对话级翻译 → 独立语义审校 → 保义时长适配 → 最终文本复核”。复用已有说话人、LLM、IndexTTS 与来源追踪模块，不引入影片专用规则，不要求用户提供剧本、人物姓名、角色介绍或标准译文。

重点是把全文理解的结果变成可追溯、可校验、能贯穿配音改写的共享数据。单纯扩大提示词、增加润色次数或切换大模型，均不足以修复当前的信息丢失。

系统可以依据当前素材推断语言风格、关系和意图，但不能可靠补全素材没有交代的背景。匿名声音身份、台词中提到的人物、被称呼的人必须分别建模。不把角色说出的指控或自述自动当成客观事实。

| `config.yaml` | `skip_stt_correction: true`；`require_speakers: false`；最低覆盖配置 0.80 | 当前配置没有强制在翻译前解决原文/身份不确定性 |

当前实际素材仅 30 条翻译行、原文约 470 字符，不能把本片问题简单归因于 8000 字符截断。主要短板是原文噪声、解释能力、角色方向及下游一致性。

当前产物 `output/log/terminology.json` 中可见：

- “合成百姓”被解释为 `synthetic common people` 并加上讽刺含义；可疑识别结果被升级成确定语义。
- “皇老爷”被翻为 `His Royal Highness`，同时存在“黄老爷 → Master Huang”；未见别名/误识别候选冲突管理。
- S01 的证据包含“给县长……惊喜”，画像却倾向把 S01 本人解释为县长；至少存在把受话者身份赋给说话人的风险，应回到对白证据复核。
- 存在 `99 → RM49`、九条改五件等来自其他任务的改写规则。

`output/log/translation_results.xlsx` 中还有风险候选：

- L00017 `翻译就是惊 → It's 'sur'...`：可能是打断、分句或识别问题，必须结合相邻原文和音频判断；不能无依据补成完整句。
- L00026 出现 `I'll give you...`：该行由 S03 复述金额条件，需核查付款主体，避免转述者变成付款者。
- L00028 将相邻称呼组织成 `Master Wang and Master Tang are my true loves!`：需要检查称呼与句子主语的区分，不能仅按无标点文本串接。

上述属于当前输入、译文和画像之间的风险证据，不使用网上台词作为正确答案。

## 3. 统一数据基础

以稳定 `utterance_id` 为主键，保留 `source_word_ids`、时间、说话人、原始 ASR、规范化文本、候选纠正、源证据和版本。当前按行号生成的 LineID 可作为兼容导出，但不应在重分句后继续冒充原来的稳定身份。

新增 sidecar，逐步接入现有 Excel，不要求整条流水线重写：

| 数据 | 必需内容 |
|---|---|
| `dialogue_units.json` | 稳定 ID、原文、词关联、时间、speaker、源不确定项 |
| `content_context.json` | 场景划分、事件链、各人陈述、已知事实/推测、信息揭示位置 |
| `speaker_profiles.json` | 匿名身份、语言风格维度、目标语言表达约束、证据与适用场景 |
| `dialogue_relations.json` | 说话者→受话者、提及实体、称谓、关系、指代、置信度 |
| `translation_decisions.json` | 术语/称谓/重复短语的译法、范围、理由、版本、原文证据 |
| `translation_review.json` | 各问题的类别、严重度、证据、修复、未解决项与实际覆盖 |

每项推断至少具有 evidence_ids、scope、confidence 和 alternatives。置信度是模型判断信号，不冒充经过标定的概率；低置信度推断不得变成强制翻译规则。

## 4. 阶段设计

### A. 源证据与上下文隔离（P0）

1. 新任务默认只使用本次媒体及从它提取的数据。外部术语表为显式可选项，绑定任务、语言和用途；正常自动路线不读取历史业务替换表。
2. 区分词汇翻译与商业内容替换；价格、数量、品牌改写不得藏在通用术语表中生效。已有资产保留，不删除全局表。
3. 自动标出人名/称谓变体、异常词组、过长词时长、重复乱码、角色切换附近的残句。
4. 对影响主语、动作、数额、否定等核心内容的异常，按原音/分离人声进行局部重识别；把候选文字及声学证据交给上下文判断。
5. LLM 只能提出纠正候选；“更符合剧情”不足以覆写原文。候选改变词数时回到已验证的声学对齐路线，不沿用虚假的旧词时间。
6. 预算耗尽仍无法确定：保留明确歧义；影响关键意思的条目标记 unresolved，不输出貌似确定的补写。

退出条件：本次理解输入来源明确；没有其他任务的规则；源文本高风险项有处理结果。

### B. 全片理解（P0）

短片：当全文与必要元数据能在模型的有效预算内完整容纳时，直接全量读取。当前 30 行短片适用，不再先把全部内容压缩成两句话。

长片：按话题、时间间隔、对话连续性形成场景单元，每个单元保留边界上下文；先分析所有场景，再汇总事件与人物变化，最后检查跨场景引用。不能只分析前缀，也不能让摘要成为后续唯一证据。

全局结果包含：发生了什么、每个人声称什么、谁问谁答、冲突焦点、每次转折、反复出现的词、承诺与条件、尚未解决的指代。

保留每个事实的出现位置。可以用后文帮助解释前文，但不得把尚未揭晓的身份或动机提前写进译文。跨场景翻译按需要取回原始对白，而不只取回摘要。

退出条件：每个对白单元都有场景归属，全文分析覆盖 100%；跨场景事实都有原文引用。

### C. 角色风格、关系与当下状态（P0）

采用三层信息：

- 相对稳定的语言风格：正式程度、直接程度、句式长短、粗口强度、讽刺倾向、犹豫习惯。多处一致证据才升级为稳定特征；单一片段只定义局部表现。
- 有方向的关系：S01 对 S02 的称呼、尊敬/敌对/试探、说话目的。被称为“县长”的对象不能自动等于正在说话的人。
- 当前台词状态：命令、请求、威胁、嘲讽、转述、追问、敷衍、打断，以及局部情绪变化。

人物性格最终要转成可执行的译文选择。例如“强硬”可影响简短命令句，但不允许增添侮辱；“犹豫”允许保留原文停顿，不允许每句凭空加结巴；“正式”不等于处处加 Your Excellency。

未知身份、受话者、关系允许 unknown。多名候选时保留候选集合。LLM 发现说话人矛盾只能请求上游声学复核，不能凭剧情推测改写 Nemotron 标签。

原片语音可作为重音、停顿、强度变化的辅助证据，默认不从音高直接推断人格、身份、年龄或性别。关键画面如需使用，只作为本片内可选证据；不将图像处理设为首版必需依赖。

退出条件：所有强制风格/称谓规则可追溯；无证据角色信息为 unknown；风格允许按场景变化。

### D. 以完整对话行为组织翻译（P1）

先确定问答、命令与回应、追问与解释、打断与续接的关系，再选择翻译块。10 行/2000 字符改为资源上限而非语义边界；超长对话可拆块，但携带未完关系和关联原文。

每块输入：场景目标、相关角色画像、受话者和指代、该块完整原文、必要前后文、已确定的译法、源不确定项、台词 ID、时间预算。

先记录短小的语义约束：谁对谁说、做什么、肯定/否定、条件、数量、言语功能、必须保留的重复或强调。无需输出冗长推理过程。

生成忠实语义版本与自然口语版本，二者都有 ID 和版本。自然版本必须保留语义约束，才可成为字幕/配音母稿。当前“直译→润色”可以保留内部实现，但不再无条件采用最后一次输出。

连续重复的“翻译翻译”应根据实际对白判断是语言转换、要求解释、还是施压追问。若证据支持“逼对方说清意思”，英文可以考虑 explain/spell it out；不能全片机械替换。保留必要的重复、逐步增强的粗口和节奏，不把表现性重复当冗余删除。

同一场景内先固定核心称谓与反复短语的选择，再允许受限并发翻译；无依赖场景可并行。场景结束统一检查局部译法与全局决策有无冲突，更新必须有版本，不能互相覆写。

退出条件：输出 ID 集合、顺序、speaker 归属完全一致；没有漏译、串句、越权补写；语义约束与译文对应。

### E. 独立审校与有界局部重译（P1）

审校覆盖整段对话和跨段依赖，逐项检查：

- 施事/受事、付款者/收款者、说话者/转述者是否混淆。
- 否定、数额、单位、条件、承诺、关键动作是否变化。
- 称呼、名字、代词与关系方向是否一致。
- 问句、反问、威胁、讽刺、回避、重复递进是否保留。
- 相同角色的语言风格是否无故变化；源片中的风格变化是否被错误压平。
- 是否新增人物背景、外部剧情、动机、解释或提前揭示后文。

审校调用独立于生成调用，先看原文与候选译文，不把生成器的自我解释当成正确答案。以结构化问题列表输出，而非只给“自然度 9 分”。数字/单位/ID 等使用确定性检查，歧义与语用用上下文判断；两者都记录依据。

首版可复用同一配置模型作独立审校，但需承认共享偏差。模型对照和高风险复核可配置另一已验证模型，不把双模型一致当成事实正确。

每处问题建议最多自动修复 2 轮；修复范围包含关联问答或转述链，完成后复查受影响关系。达到预算仍未解决则停留在草稿/待复核状态，不继续润色掩盖。

退出条件：无未解决的严重语义错误；低风险歧义明确保留；自动检查覆盖与拒绝项可见。

### F. 保义的配音时长适配（P1）

把审核过的自然口语稿作为母稿。字幕排版与配音时长分别生成视图，保留同一个 utterance_id 和母稿版本。

Step 5、8、10 及修复路径统一接收最小上下文包：源语义约束、角色风格、当前语气、受话者、重复链、相邻回应、已定称谓、硬时间边界。

缩写可以换简短同义表达、自然省略可恢复成分；不能删除关键谓语、反问、否定、数额、重要称呼，或把转述改成第一人称承诺。不要只为填满空白添加剧情或废话。

每次缩写/扩写/文本清洗后，对照原文与母稿重新做语义检查；未通过的候选不得进入 TTS。TTS 实测过长时，只在同说话人且允许的间隙调整、换更短的等义表达、重生成或有限变速，不侵占下一角色边界。

TTS 回读只检查“声音是否读对当前稿”，另一个检查负责“当前稿是否译对原文”。两类报告分开，不用回读分数替代翻译验收。

退出条件：最终 spoken_text 能追溯母稿；最后一次改写通过语义复核；时间指标沿用项目既有有效发声验收。

## 5. 接入位置与实施顺序

| 批次 | 工作 | 主要模块 | 验证 |
|---|---|---|---|
| M0 | 冻结基线，隔离全局术语/业务替换，建立源异常清单 | Step 4 summary、配置、translation_state | 无跨任务术语注入；原资产不变 |
| M1 | 全文/分场景理解、三层角色状态、有向关系、稳定 ID | translation_context、Step 4 summary、prompts | 全文覆盖、引用有效、指代方向、长片尾部信息 |
| M2 | 对话单元翻译、共享译法决策、独立审校及局部修复 | translate_once、Step 4 translate、审校模块 | 问答/转述/重复/否定/称谓回归 |
| M3 | ID 与上下文贯穿字幕及配音改写；所有文本变更重新验收 | Step 5、Step 8、dubbing_rewrite、Step 10 | 原译文正确但缩写破坏语义的案例必须拦截 |
| M4 | 阶段缓存依赖、对照试验和推广 | translation_state、pipeline、现有测试/benchmark | 缓存失效正确、成本记录、不同类型素材泛化 |

每个新产物指纹包含本次源文本、speaker 版本、场景/角色/术语决策版本、目标语言、模型与提示词版本。只重跑受影响场景、台词和下游音频；背景混音链路保持既有修复。

不同时更换工作流和默认模型来比较效果。先固定模型验证流程收益，再用相同素材比较模型。执行代理模型与项目翻译模型是两个独立设置。

## 6. 验收标准

以下为方案目标，不是当前实测成绩。

| 维度 | 验收标准 |
|---|---|
| 自包含 | 自动运行不输入剧本、人物名单、外部标准译文、历史任务替换规则 |
| 全文覆盖 | 100% 对白单元进入场景分析；长片没有前缀截断导致的未分析段 |
| 可追踪 | 100% 最终台词有源 ID、speaker 状态、母稿及改写版本；不丢失/重复/串位 |
| 推断约束 | 强制角色/关系/术语规则 100% 有有效原文引用；缺证据为 unknown；引用存在仍需检查是否支持结论 |
| 语义安全 | 没有未解决的关键施受事、否定、数额、条件、动作和指代反转；承认自动审校可能漏检 |
| 角色一致性 | 无未解释的称谓/语域变化；有源证据的情绪变化允许保留 |
| 下游保护 | 每次影响 spoken_text 的改写都有新审校结果；旧报告不能复用到新文本 |
| 状态诚实 | 源不确定、严重语义分歧、缺失审校不得报告 accepted；报告自动覆盖和真实限制 |
| 真实改善 | 在冻结的离线保留集上，严重语义错误少于基线，角色语气/自然度盲评改善且时长适配不退化；样本数与分项结果公开 |

生产任务无需人工人物核验。离线研发评估可以使用人工标注的自制/已有授权测试对白，只用于检验系统是否变好，不把这些答案注入生产任务。没有参考标注时不能报告“翻译准确率 99%”；模型自评分也不能作为该准确率。

回归案例至少包含：被称呼者与说话人不同、同人跨场景语气变化、第三人转述付款条件、连续逼问、真实打断、称谓同音误识别、多人同名指代、长片后半段揭示信息、强背景 ASR 噪声、短句适配和无关术语表存在。加入“应该保持未知”的负例，防止为了通顺自动编造。

## 7. 对照试验和成本控制

保留四组：A 当前流程；B 只修输入隔离和源异常；C 加全文/角色/关系与对话翻译；D 再加独立审校及配音改写保护。相同源素材和模型、保存源纠正差异，可区分识别改善与翻译改善。

分别比较：原文→翻译母稿、母稿→实际配音稿、配音稿→回读。记录严重错误数量、角色/指代问题、自然度评价、未解决比例、耗时、模型调用量、重试与缓存命中。现有 30 行片段只作一个回归样本，不能代表所有影片。
