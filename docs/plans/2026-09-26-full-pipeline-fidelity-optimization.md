# 全流程配音还原度：证据审计与实施方案

日期：2026-09-26。状态：用户已授权全阶段实施、独立目录从源视频重测及 GPT-6 Astra 最终审核。授权登记时工程改造尚未实施；进度以各阶段证据更新。

## 1. 目标与边界

以输入视频本身为唯一内容依据，使英文版保留原片的内容、匿名说话人身份、人物关系、表演变化、停顿与打断、音乐、环境声及动作声。日常运行不依赖电影剧本、角色名单、外部人物资料或人工逐条指定角色。

继续使用本地 MLX IndexTTS 主路线和 Nemotron-MLX。保留用户确认的混合参考：完整长句使用当前原句作为音色和情绪参考；短句/碎句使用同说话人稳定锚点加当前原句情绪。身份未知时不得借用其他角色。

跨语言的音素、句法、字数和发声动作不同，“100% 原样复制”不能作为可证明的统一指标。工程目标是：关键含义无损、角色不串音、表演不被抹平、真实发声锚点同步、背景事件完整、所有不确定性可追溯。单纯增加翻译轮数、统一提高情绪权重或填满音频窗口不足以实现这些目标。

本方案承接 `2026-09-25-autonomous-dubbing-optimization.md` 与 `2026-09-26-speaker-emotion-conditioning.md`，以下以当前代码及本次测量为准，旧计划中的历史参数不能直接当作现状。

## 3. 目标流程与数据契约

```text
源视频与配置/模型快照
  ├─ 保持原声道、原采样率的无损母带 → 分离 → 连续背景与原声事件
  └─ 16 kHz 单声道分析副本
       ├─ 主 ASR + 原生词时间 + 局部独立识别
       └─ Nemotron 概率/重叠 + VAD
                 ↓ 对分歧区局部重识别与重新对齐
       不可变源词/源事件 → 说话轮次 → 表演单元
                 ↓
       全文事实与关系证据 → 场景/对话意图 → 受约束的英语候选
                 ↓
       混合音色/情绪参考 → IndexTTS 自然生成 → 多维门禁/有限候选
                 ↓
       真实发声与停顿适配 → 场景声场渲染 → 原声事件/背景混音
                 ↓
       最终音轨核验 + 按实际发声生成字幕 → 可追溯交付
```

将 Excel 从唯一事实源改为可编辑视图；增加版本化结构记录，不需要重写全部模块。

- `source_word`：word_id、文本候选、原音起止、ASR 模型/置信信息、纠错与重新对齐来源。
- `source_event`：event_id、speech/nonverbal/ambience/uncertain、原始起止、检测依据、保留策略。
- `utterance`：utterance_id、word_ids、speaker 候选/分差、重叠、原始发声/停顿、场景、对话行为。
- `performance_unit`：utterance 的子范围、语气转折、重音/停顿锚点、参考来源和置信度。
- `translation_candidate`：对应源 IDs、目标文本、施事/受事/受话人/转述来源、数字否定称谓、语气强度、估计时长。
- `take`：实际音色/情绪参考 hash、权重、模型版本/量化/种子、实际生效时长参数、原生输出、回读、身份/表演/时长检查。
- `render_event`：所选 take、真实发声范围、场景响度/声像/混响、背景/原声掩码、字幕、最终音轨 hash。

源音时间、字幕显示时间、TTS 可用窗口、实际发声时间必须分开存储。任何改译、分句、变速都不能改写源音事实。源文字修订后只重对齐相应原音范围，并按依赖关系使下游失效。

## 4. 每个板块的具体改造

### 4.1 输入与母带

- 抽取浮点 PCM 或 FLAC，保留源采样率、声道布局与音视频起始 PTS；分析副本才降为 16 kHz mono。
- Demucs 使用无损母带，按模型需要转换采样率，保留转换映射。声学分析副本不得流入最终混音。
- 模型原生 TTS 可继续 mono/24 kHz；最终混音统一一次转换至交付采样率，例如 48 kHz。升采样不应被宣称提高音质。
- 检查声道布局、时长、编码延迟及时间原点；输入变化使分离、ASR、角色、翻译和参考失效。

涉及：audio_preprocess、demucs_vl、constants、pipeline/artifact_manifest。

### 4.2 分离与原声事件

- 保留已有 Demucs 作为基线，先修输入链路，再做分离模型对照。不能把音乐人声分离自动等同于电影“对白/音乐/音效”三轨。
- 同时保存原始混音、人声、连续背景及各自增益/延迟；避免分别 rescale 后没有增益回执。
- 在原视频内检测笑、喘、叹、喊、咳、冲击声等事件；语言性的“啊/嗯”与纯非语言声音分别处理，不能按短字串直接删除。
- 无源对白的可靠区间恢复原始声场；对白区使用分离背景。源对白掩码来自原音检测，不能依赖生成对白窗口，否则漏识别的原语言可能残留。
- 对对白与动作声、笑声真正重叠的区域，标记高风险并比较局部分离候选；没有干净源轨时不能保证无损恢复。
- 只有通过去重判断的原始非语言事件才能回加，避免与 TTS、背景或原音残差双重叠加。

验收：连续背景存在；未出现新原语对白泄漏；已检测关键事件无缺失/重复；同一采样时基；保留增益和延迟证据。无干净真值轨时不报告 SI-SDR 或“100% 分离”。

### 4.3 ASR 与源文纠错

- 基线继续保留 stable-ts/WhisperX 词时间路径；将 large-v3 与现有 turbo 在原混音和分离人声上做同输入对照，优先只处理疑难区间。
- 使用不同识别模型提供局部文本见证；保留主模型、见证模型、原混音、人声四类输入的分歧证据，不以多数票直接宣称真值。
- 保留概率等可用置信信息；置信度缺失就明确缺失，不能伪造默认高分。
- 根据原音 VAD/Nemotron 活动建立连续语音覆盖，关注时段内缺口，不再只看每个 turn 是否命中一次。
- 高风险触发：名称不一致、不可解释词串、数字/否定分歧、反复台词漏读、切块边界、短插话及异常长词。
- 重识别采用上下文重叠与按时间合并；禁止全局按文本去重，以免删除真实重复质问。
- LLM 只能提出候选修订；候选必须返回原音对齐和声学证据。对齐成功只证明位置可匹配，不证明识别内容正确。

验收：原始词与候选均可回溯；可疑源文不会直接被润色成“确定剧情”；普通运行无需外部台词。CER/WER 只用于拥有人工原音标注的开发基准，不作为无真值运行的虚构分数。

### 4.4 Nemotron 角色与重叠

- 保留完整多说话人活动概率与时间分辨率；报告原始列到匿名角色的映射、实际模型 revision 和生效参数。
- 单角色判定同时参考第一/第二候选分差、连续区间、短句可靠性。置信不足时保留 UNKNOWN，不能为提高覆盖率强行贴标签。
- 真实重叠保留多标签；先区分正常接话、打断与同时说话，再决定能否局部分离，不在 argmax 中把另一人抹掉。
- 以同角色参考池的聚类一致性作第二证据，检查混人和身份漂移；角色标签不能自证参考纯净。
- 保持 S01/S02/S03 只表示录音内身份；人物地位、情绪、音高变化都不得被当作换人规则。

验收：重叠和 UNKNOWN 独立统计；不把分配率等同于 diarization 准确率。DER/JER 需要开发基准的时间标注，日常无标签任务报告一致性与风险。

### 4.5 分句、轮次与表演单元

- 字幕断行与配音分句解耦，禁止视觉长度反过来切断人物表演。
- 先以说话人变化和原音轮次为边界，再结合语义、原音停顿、相对音高/能量变化识别表演单元。
- 长句若表演连续，保留原句双参考和整句生成；仅在有明显转折或打断证据时建立子单元，不按固定 2 秒机械切碎。
- 短句/碎句照常用稳定锚点加原句情绪；不能因英文翻译变长就改变源句分类。
- 将重复、欲言又止、半个词、呼吸与停顿显式保存。字幕可以合并显示，声学事件和来源映射不得丢失。

验收：源词/源事件映射覆盖闭合；无跨说话人合并、无重复合成、无凭长度删除真实反应。

### 4.6 全文理解与翻译

- 建立三层上下文：全文可证实事实和关系、场景内目标与权力变化、当前对白意图/受话人/情绪。区分相对稳定的说话风格和当句状态。
- 每个推断绑定 utterance_id、证据范围和置信度；含混指代保留备选。“谁欠谁钱、谁替谁传话”是事件关系，不能由 S03 或演员模板决定。
- 给翻译同时输入源句、前后轮次、场景状态、术语决策和表演要求；关键重复/粗口/讽刺/迟疑不能在“自然英文”阶段被自动删弱。
- 输出少量候选：忠实版、可演绎版、必要时的紧凑版；先检查施受事、否定、数字、称谓、转述和言语行为，再按时长选择。
- 审查分为结构约束、原音分歧复核与语义审查；可采用不同模型作评审，但模型分歧仍不是原音真值。
- 删除影片特定规则，代之以可追溯转述关系。审查异常返回 failed/pending；修订后重新检查，最多两轮；重复无改善则保留问题而非显示通过。
- 生成前时长改写和后续修复必须重新走关键语义检查，防止已审查译文在 TTS 修复时退化。

验收：每条关键事实与表演约束有审查记录；第 17 类半句话、第 21 类强烈质问、第 22 类感叹、第 28 类指代关系作为回归类型，不写成本片专用答案。

### 4.7 音色与情绪参考

- 统一从无损人声截取参考，按源词/表演边界保存，检查其他说话人污染；任务窗口不等于干净参考窗口。
- 长句：原句同时提供音色和情绪，保持用户策略；若确认混入他人或损坏，回到上游修复或显式报风险，不静默全部切换成锚点。
- 短句/碎句：同人多候选池选稳定锚点，原句提供情绪。候选按纯度、噪声、削波、有效语音和声纹一致性选，不能只选最长或最低音。
- 两条清理路径不同：音色参考允许适度去噪；情绪参考尽量保留呼吸、力度和内部停顿，避免强归一化压平表演。
- alpha 首选现行 1.0；只有失败单元才对比备用锚点或 0.85 等有限候选。长句两参考相同时调整插值 alpha 通常没有解决句内韵律的作用。
- 生成回执须记录实际后端/权重/输入及其 hash；目前计划回执还应补强实际生效参数，不能只记录请求。

验收：身份与情绪分别合格；不能牺牲任一项换总分；不得用绝对 F0、性别预设或单一编码器分数作最终裁决。

### 4.8 IndexTTS 生成与候选选择

- 保存自然输出与适配后输出两个版本。记录原生 duration_factor/fit_duration、实际生成时长、所有后处理倍率，暴露隐藏二次变速。
- 首先生成一个候选；失败才按根因局部重试，总候选建议上限 3：换同人锚点、调整情绪权重、换语义等价紧凑译文分别独立比较。
- 内容失败回到发音/文本；身份失败回到角色/参考；情绪失败回到表演单元/参考；超时失败回到翻译和时间预算，不能统一靠加速。
- 专名/计量单位使用后端经本机验证支持的发音控制；例如 taels/tiles 不能仅凭平均回读分数当作无差别。
- 对源文“啊/我……”保留其反应功能，不能填长成一句无依据的英文。短句 ASR 不稳定时结合原音和上下文、多次证据，标记不确定而非擅自变静音。
- 内容、身份、表演、同步独立为门禁；通过后才按自然度排序。无候选全部通过时输出带风险的预览，不降级为平静默认音色。
- 模型/量化精度对照只在清洁参考和时间轴已经稳定后进行；8bit 本身不能直接被认定为串音根因。

### 4.9 真实发声与时间轴

- 保留原音与生成语音的真实 VAD/词对齐、重音、内部停顿。使用目标语言对齐器定位生成词，不能要求中英音素一一对应。
- 同步优先级：角色接话/打断、关键语义重音或动作点、发声起止、内部停顿；字幕显示窗口是独立约束。
- 先选自然时长候选，再作有边界的语义压缩；轻微适配只处理允许的语音/停顿区域，保留低声和呼吸。
- 禁止把整段余量堆到句尾来证明同步。允许原片真实留白，不为填窗口机械加词。
- 全部后处理倍率计入报告，采用相同的生成/评测限值。现有常规 1.12 与短句 1.35 的策略差异要显式报告，并在基准中校准，不能通过放宽评测隐藏告警。
- 对跨角色硬边界保持零越界；对白本来重叠的场景使用独立轨，不强制串行化。

验收：排程偏移和发声偏移分开。建议以当前 120 ms 起点/180 ms 终点作为首轮发声门槛候选，关键停顿/打断另设 150 ms 初始误差预算；这些是待标注校准的工程值，不是已经达成或通用的人耳标准。每条超限都可定位原因。

### 4.10 场景混音与非语言事件

- 使用完整立体声背景作为连续底层；在确认没有原语对白的区间，以延迟/增益对齐的原声残差补回真实声场。不能同时叠两份完整背景。
- 以源对白掩码控制原声恢复，掩码边沿做小范围平滑并避开爆破音、冲击声；TTS窗口只决定新语音位置。
- 非语言人声单独事件化，在没有被底层/残差/TTS重复保留时回加。重叠无法干净提取时标为 uncertain。
- 对白相对原片按场景调整响度、远近和声像；轻声与喊声保留相对动态。混响/均衡只在估计可靠时有限应用，不能用全片固定混响掩盖音色问题。
- 背景无需统一 ducking；若清晰度确有问题，仅在对白区域做温和、有上限的局部调整并测动作声。
- 最终总线上测真实 LUFS、LRA、true peak；用共同增益满足交付目标，避免逐句压成相同响度。当前未见过载，不将“加限幅器”列为已证实根因修复。

验收：母带声道保真、原声保留分支实际进入混音、连续背景和事件完整、无原语泄漏/双重人声/新爆音；最终编码后仍满足峰值与时长要求。

### 4.11 字幕与视频封装

- 视频保持原 PTS/镜头节奏，声轨按同一媒体原点封装；检查流起点、结尾、解码与字幕关键帧。

## 6. 验收标准：硬约束与感知质量分开

**可确定检查的硬约束**：输入/输出 hash 与参数完整；每个接受的源对白/事件都有映射；零已知跨角色借参考；无已知漏句/重复/截词；数字、否定、关键称谓和转述关系没有未解决严重项；字幕与最终译文一致；背景/事件完整；实际门禁失效不得标 accepted。

**声学同步初始目标**：逐句报告真实 onset/offset、关键停顿、接话/打断锚点，而不是补齐容器长度。120/180/150 ms 为候选工程预算，需原音标注基准校准；跨语言不要求逐音素同长。视频时长差按源帧时长和音频编码帧容差检验，并单独检查流开始时间。

**音色**：独立声纹模型比较同角色/其他角色及同人异情绪样本；短句按角色聚合诊断但保留逐条风险。阈值需在同数据长度、语言和情绪条件下校准，不能照搬 0.7 或用 F0 判男女。不用生成模型自己的声纹编码器作为唯一裁判。

**情绪与表演**：分别评估愤怒/讽刺/迟疑等对话行为、相对音高变化、能量轮廓、停顿与强调锚点。跨语言可以不同音素，不应丢掉相同的表演意图。IndexTTS 内部情绪向量只能作诊断，需独立方法和开发阶段盲听校准，避免模型自评闭环。

**混音**：当前源视频无需强迫为某个固定 LUFS；按目标交付标准记录总线响度/真峰值，并保持场景间相对动态。建议成片 true peak ≤ -1 dBTP 为首轮交付上限；这不替代对白清晰度、原事件保留和空间听感验证。

**整体通过**：各维度分别满足，不能用平均回读分数抵消某句角色串音或情绪丢失。自动代理指标未校准时，整体必须保持 perceptual_pending。

开发基准至少覆盖：当前片段、其他快速多人对话、安静/低声场景、带音乐与动作音效场景。按短句/长句/激烈情绪/重叠/专名分别报告。人工从输入原音做标注和盲听仅用于开发验收，不作为每个正常任务的外部角色资料依赖。保留未参与调参的视频，防止再次为这一部影片过拟合。

## 7. 实验顺序与故障定位

对同一批高风险单元依次比较：旧版→仅修无损输入/分离→修源文与角色→修理解/翻译→修混合参考/表演单元→修时间轴→修混音。每一步固定无关变量，既看单句也听连续上下文。

- 原音识别就错：回到 ASR，不调 TTS。
- 文本意思正确但角色/指代错：回到分配与关系证据，不用声纹修语义。
- 原生 TTS 已串音：检查参考纯度、角色、模型；适配后才失真则检查变速/裁边。
- 原生表演正常、混音后显得平：检查响度、动态、背景遮蔽及空间渲染。
- 单句均正常、连起来不对：检查接话/打断、跨句语调、事件位置与场景节奏。

最终交付包应包含：独立 run 的带字幕视频、无损混音、背景与对白/非语言轨、逐行来源/实际参数、源文分歧与翻译审查、裸生成与适配后指标、最终音轨验收和可定位的剩余问题。
